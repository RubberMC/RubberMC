# RubberMC (0.1.0)

An experimental Rust-native Minecraft server project exploring compatibility with existing Fabric mods. 

## What it does now

-Nothing

## What it does NOT do

This is not a playable Minecraft server or a replacement for Fabric Loader yet.

## Build

Requires Rust and Cargo.

```sh
cargo build --release
cargo test
cargo fmt --check
```
